# Reaction Game

Простая игра на реакцию: кнопка становится зелёной в случайный момент — жми как можно быстрее и узнай своё время в миллисекундах.

## Как играть

Открой `index.html` в браузере или задеплой на любой статический хостинг (например, GitHub Pages).

## Telegram Mini App

Страница подключает `telegram-web-app.js`, поэтому её можно открыть как Telegram Mini App — просто укажи URL сайта в настройках бота у [@BotFather](https://t.me/BotFather). Вне Telegram игра тоже работает как обычная веб-страница.
